# Redoy Sarker

Personal portfolio website of **Redoy Sarker**, Computer Science and Engineering graduate and machine learning researcher from Sylhet, Bangladesh.

**Live site:** https://personalportfolio-coral-five.vercel.app/

## About

A single-page, responsive portfolio that presents my profile, research, skills, activities and certificates.

## Highlights

- Animated hero with a typing role line and a 3D tilt photo
- Research section with animated counters (PoliSent thesis)
- Technical and soft skills, activities and certificates
- Mobile menu, smooth scrolling and active section highlight
- Light and dark theme that follows the device setting

## Built with

HTML, CSS and vanilla JavaScript in one file. No frameworks and no build step.
Fonts: Fraunces, Manrope and IBM Plex Mono from Google Fonts.
